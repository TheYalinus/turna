# turna
A C++ library for all your download needs. Powered by LibCurl.
## Why ?
This library is a part of my Download Manager project. I Just wanted to put it into another repository so another people can use this library too.
## How to build ?
create a build folder (in source builds will be rejected by cmake) and run cmake .. then make 
## What means turna?
Turna is the Turkish word for the crane.
